\begin{coqcode}
  Fixpoint valid_tree A ~$\coloneq$~
    match A with
    | TA _ | OK | KO ~$\Rightarrow$~ ~$\top$~
    | Or ~$\square$~ _ B ~$\Rightarrow$~ valid_tree B
    | Or ~$\boxed{\texttt{A}}$~ _ B ~$\Rightarrow$~ valid_tree A && 
          ((B == KO) || B.base_or B)
    | And A B0 B ~$\Rightarrow$~ valid_tree A &&
        if success A then valid_tree B 
        else B == big_and B0
    end.
\end{coqcode}
